# VM0042 alignment and limitations

This repository is structured around Quantification Approach 1, Measure and Model.

Controls include the same measured initial SOC for baseline and project scenarios, distinct management schedules, separated calibration and validation sets, traceable activity data, and separate uncertainty outputs.

Before project use, the RothC implementation, sampling plan, equivalent soil mass procedure, laboratory methods, model validation, uncertainty calculation and independent expert review must be completed under the applicable Verra requirements.
