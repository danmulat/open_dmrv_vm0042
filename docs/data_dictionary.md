# Core data dictionary

| Field | Definition | Unit |
| --- | --- | --- |
| stratum_id | Stable identifier for a homogeneous accounting stratum | text |
| unit_id | Field, farm or homogeneous quantification unit | text |
| observed_soc_t_c_ha | Measured SOC stock | t C per ha |
| baseline_soc_t_c_ha | Modeled baseline SOC stock | t C per ha |
| project_soc_t_c_ha | Modeled project SOC stock | t C per ha |
| dmi_kg_day | Animal dry matter intake | kg DM per head per day |
| methane_conversion_factor_percent | Fraction of gross energy converted to methane | percent |
| crop_yield_project_t_ha | Project crop yield | t per ha |
| pasture_project_t_dm_ha | Project pasture production | t DM per ha |
