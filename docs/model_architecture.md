# Model architecture

1. Define eligible areas, strata, quantification units, onboarding dates and management histories.
2. Measure initial SOC stocks and use the same starting stock in baseline and project simulations.
3. Simulate baseline continuation and project management separately.
4. Estimate woody biomass, enteric methane, manure emissions, soil emissions and farm energy.
5. Report productivity alongside carbon and greenhouse gas outcomes.
6. Validate each model within its applicability domain.
7. Propagate sampling, laboratory, activity data and model uncertainty.
8. Freeze model, data and parameter versions for each verification period.
