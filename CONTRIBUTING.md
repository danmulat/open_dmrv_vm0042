# Contributing

Contributions are welcome through issues and pull requests.

Before submitting changes:

1. Install the development dependencies with `pip install -e ".[dev]"`.
2. Run `pytest`.
3. Run `ruff check src tests examples`.
4. Document any change to equations, model parameters, uncertainty methods or data structures.
5. Do not describe a change as VM0042 compliant without supporting methodology review and independent validation.
